# Validation reports

**The current live-game revision is documented in `live/validation.md`.** The JSON files in `live/` record the current production export, live contract reads, roots, browser interactions and byte audit.

Other files in this directory are retained historical reports for the earlier demo. Their measurements and screenshots do not describe the live app. Historical report images totaling 5,191,342 bytes were removed for the 8 MiB submission budget; old image links are therefore archival references. No application artwork or required runtime asset was removed.
